AI Children's Story with AI Illustrations

Project Description

This project generates creative and interesting stories for children using Python. Users can enter a child's name, an animal, and a place to create a magical story.

Technologies Used

- Python
- Random Module

Features

- Generates children's stories.
- Accepts user input.
- Provides a moral at the end of the story.

How to Run

1. Open the Python file.
2. Run the program.
3. Enter the child's name, animal, and place.
4. Read the generated story.

Sample Output

Child's Name: Riya
Animal: Rabbit
Place: Forest

Story: Once upon a time, Riya found a magical Rabbit in Forest. They became best friends and went on an exciting adventure.

Moral: Always be kind and help others!
